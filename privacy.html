Privacy Policy

Hermes Mail · Effective 2026-10-28

1. Who this covers

Hermes Mail is a personal desktop utility operated by a single individual for their own Gmail account (zhangbo366@gmail.com). It has exactly one user: the owner of that account. There are no other users, no accounts, and no registration.

2. What data is accessed

With the owner's explicit OAuth consent, the application may access:

  • Message content (headers, body, attachments) of the owner's own mailbox — to read, summarise and search the owner's own mail;
  • Sending capability — to send email from the owner's own address on the owner's instruction;
  • Draft creation — to stage messages for the owner to review.

The application never accesses any other person's mailbox, and never accesses contacts, calendar, Drive or any other Google service.

3. How data is stored and protected

  • All processing happens locally on the owner's macOS computer. There is no backend server.
  • OAuth access and refresh tokens are stored in local files with 0600 permissions (readable only by the owner's OS account).
  • Message content may be cached in local files or a local database on the same computer to support search and summarisation. It is never uploaded to a third-party storage service.
  • Transmission to and from Google uses HTTPS/TLS as required by the Gmail API.

4. Sharing and disclosure

No mail content, token or metadata is sold, rented, shared or disclosed to any third party. No analytics, telemetry, tracking pixels or advertising SDKs are used. No human other than the owner reads the data.

5. AI assistance disclosure

Message content may be passed to a large-language-model API chosen by the owner in order to produce summaries, drafts or classification, only when the owner requests such a function. The owner controls which provider is used; the result is returned to the owner's own machine and is not retained by this application for any other purpose.

6. Retention and deletion

  • Local caches and tokens can be deleted at any time by deleting the corresponding files on the owner's computer.
  • Authorization can be revoked at any time at https://myaccount.google.com/permissions, which immediately invalidates the stored refresh token.
  • No copy of the data exists anywhere else, so revocation plus local deletion is complete erasure.

7. Google Limited Use compliance

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements:

  • Gmail data is used only to provide the user-facing features described above (reading, searching, drafting and sending the owner's own mail).
  • Gmail data is not used to train, improve or develop generalised or non-personalised AI/ML models.
  • Gmail data is not transferred to third parties except as necessary to provide the feature the owner requested, for security purposes, or to comply with applicable law.
  • Gmail data is not used for advertising, and is not sold.
  • Humans do not read Gmail data, except the owner themself.

8. Children

Not applicable — the application is not directed at or available to anyone other than its single adult owner.

9. Changes

Any change to this policy will be published on this page with a new effective date.
