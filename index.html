Hermes Mail

A personal Gmail automation utility · 个人 Gmail 自动化工具

What this application is

Hermes Mail is a single-user, locally-run desktop utility. It is not a public service and has no web sign-up. It runs on the personal macOS computer of its owner and connects to the Gmail API solely so that the owner's own assistant software can read the owner's own inbox and send email from the owner's own account.

本应用是单人使用的本地桌面工具，不对外提供服务、没有注册入口。它只运行在所有者本人的 macOS 电脑上， 通过 Gmail API 让所有者自己的助手软件读取本人的收件箱、以本人身份发送邮件。

Scope of access

  • gmail.send — send mail from the owner's account only.
  • gmail.compose — create drafts in the owner's account.
  • gmail.readonly — read and search the owner's own messages.

No other Google account, mailbox, contact list or calendar is ever accessed.

Where data lives

All mail data is processed on the owner's computer. OAuth tokens are stored in a local file readable only by the owner (chmod 600). No mail content is sent to any third-party server, and there is no analytics, tracking or advertising of any kind.
